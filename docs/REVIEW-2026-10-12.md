# v3 audit — 12 Oct 2026

Whole-app review (v3 only). Read this before starting another audit: it lists what was checked,
so a new session doesn't spend tokens re-deriving it.

## Checked and fine
- Every `'use server'` action opens with `requireSession()` (directly or via `guard()`/`remove()`/`gate()`).
- Crons and the Telegram webhook fail closed (`safeEqual`, unset secret never matches).
- Session cookie: signed, expiring, Google accounts re-checked against `app_users` on every action.
- Invoice PDF/preview routes re-check the session.
- No `[data-world="hud"|"contact"]` remnants.

## Fixed in this pass
- Viewer role is read-only (`canEdit()`, `requireSession()` in `lib/auth.ts`).
- Production with no session secret fails closed (`openDoor()` in `lib/session.ts`).
- "Today" is Malaysia time everywhere money/dates are judged (`lib/today.ts`). Before, 00:00–08:00 MYT
  counted as yesterday: overdue flags, YTD windows, and the invoice-number month on the 1st.
- Dead v3 code removed (Bars, KitMotion, dashboard/Owed, buildLedger, embedUrl, isFiltered).
- Root CLAUDE.md split (28 KB → 16 KB); topic files: `app/(app)/property/CLAUDE.md`,
  `app/(app)/invoices/quotes/CLAUDE.md`, `app/hello/CLAUDE.md`, `docs/TOOLING.md`, `docs/SHOWCASE.md`.
